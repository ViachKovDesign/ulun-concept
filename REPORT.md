# Отчёт: концепт-сайт «УЛУН» — интерактивный гид «Как заварить чай правильно»

## Что сделано

Одностраничный сайт вымышленной московской чайной «УЛУН», без сборщика (HTML + CSS + JS).

1. **Шапка**: знак-листик «УЛУН», меню (на телефоне раскрывается кнопкой, закрывается по Esc и клику мимо), кнопка «Чайная».
2. **Hero**: заголовок «Хороший чай — это 4 числа», большая иллюстрация — улыбающийся чайник с паром, чашка, листья. Четыре числа (90 °C · 7 г · 20 с · 7 проливов) на примере улуна, со счётчиком при загрузке. При скролле чайник наклоняется, листья уплывают с параллаксом.
3. **Интерактивная заварка — 6 глав** (каждая — отдельный экран, на десктопе закрепляется pin-ом):
   1. «Выбери чай» — 5 карточек-радиокнопок (зелёный, белый, улун, красный, пуэр) со своими иконками; банка-чайница с лицом показывает выбранный чай и описание. Выбор меняет все параметры дальше.
   2. «Вода» — нативный ползунок 60–100 °C; в стеклянном чайнике меняются пузыри (тихая вода → крабьи глаза → рыбьи глаза → нити жемчуга → бурное кипение), растёт столбик термометра, подсвечена зона нужного чая, меняется выражение лица чайника; вердикт «Попал! / Горячо / Холодно» с объяснением.
   3. «Сколько листа» — весы: ползунок 0–12 г и кнопки «± щепотка» (≥ 44 px); листья падают в чашу, стрелка с пружинкой, зона рекомендации на циферблате, совет «на 200 мл — ×2».
   4. «Пролив» — кнопка «Залить»: чайник наклоняется, льётся струя, вода наполняет гайвань, лист **разворачивается (SVG-морфинг)**, запускается таймер с кольцом прогресса на время первого пролива выбранного чая; в конце — крупное «Сливайте!» и кнопка «Заново».
   5. «Сколько проливов» — 10 чашек-индикаторов (точно / возможно / нет), расписание каждого пролива с прибавкой секунд и сравнение пяти чаёв полосами.
   6. «Твоя шпаргалка» — карточка-билетик с выбранными параметрами и пометками, если пользователь промахнулся с температурой или граммами; «Скопировать шпаргалку» (clipboard с фолбэком на выделение текста) и таблица «Все пять чаёв коротко».
4. **«Частые ошибки»** — 5 карточек, у каждой две мини-иллюстрации «Не так» (пунктир) / «Так» (заливка).
5. **Чайная** — атмосферная иллюстрация (арочное окно, лампа, полки с банками, столик с чайником), факты и демо-форма записи (дата, время, гостей, имя, телефон) с проверкой полей → «Запись принята (демо)».
6. **Подвал** с плашкой «Концепт-проект. Бренд вымышленный. Дизайн и разработка — ViachKovDesign» → https://viachkovdesign.github.io.

## Как реализованы фишки

- **Строго два цвета**: зелёный чайного листа `#1E4230` и бледно-рисовый `#F2EDDC`. Все цвета — через CSS-переменные `--fg/--bg`; класс `.is-inv` меняет их местами, поэтому одни и те же SVG-иллюстрации автоматически перекрашиваются на тёмных главах. Оттенки — только прозрачность этих двух цветов. Других цветов в CSS и SVG нет.
- **Иллюстрации**: все нарисованы вручную в inline SVG (символы `<symbol>` для листьев, иконок чаёв, чашек). У предметов есть лица — дружелюбная подача; глаза моргают CSS-анимацией.
- **Морфинг листа**: свой, без плагинов. Две формы (скрученный шарик и раскрытый лист) записаны одинаковой последовательностью кубических кривых; функция `morphPath` интерполирует все числа по прогрессу. Первые 30 % раскрытия — во время заливки (твин GSAP), остальное — синхронно с таймером.
- **Таймер**: `requestAnimationFrame` + `performance.now()`, кольцо — `stroke-dashoffset`. Время можно ускорить параметром `?speed=N` (используется в тестах).
- **Пузыри**: пул из 44 SVG-кругов, пять режимов (количество, размер, скорость, «цепочки», покачивание). Анимация крутится только когда чайник на экране (IntersectionObserver).
- **Скролл**: Lenis (плавность) + GSAP ScrollTrigger: оживление hero, появление сцен глав, pin глав на десктопе ≥ 1024×700 с лёгким «дыханием» сцены. Pin создаётся только если глава помещается в экран.
- **Курсор-листик**: `gsap.quickTo`, наклоняется по скорости мыши, на тёмных зонах перекрашивается, над кнопками увеличивается. Только мышь, не на тач и не при reduced-motion.
- **Данные**: `data/teas.json` грузится через fetch; при открытии через `file://` или ошибке используется встроенная копия (`tools/inline-data.py`).
- **reduced-motion**: нет Lenis, pin, параллакса, пара и моргания; заливка мгновенная, лист сразу раскрыт, таймер работает. **Без JS**: интерактивные элементы скрыты, главы читаются как статья, есть таблица параметров, весы и термометр отрисованы статически.
- **Доступность**: семантические секции/article, skip-link, видимый фокус, радиокнопки в fieldset/legend, нативные range с `<label>` и `<output>`, `aria-live` для вердиктов и статуса таймера, `aria-invalid` + текст ошибок в форме, тач-зоны ≥ 44 px, контраст 9.55:1.

## Что упрощено

- Морфинг — между двумя формами с одинаковой структурой, а не произвольных SVG (надёжно и легко, но новые формы нужно рисовать в той же структуре).
- Pin глав только на широких и достаточно высоких экранах; на телефоне главы идут потоком с анимацией появления.
- Таймер считает только первый пролив; следующие показаны расписанием в главе 5.
- Форма — демо: ничего не отправляет и не хранит.
- Объём сосуда зафиксирован на 100 мл (с подсказкой для 200 мл).
- Таблица «Все пять чаёв» и подписи карточек продублированы в HTML вручную (для версии без JS), а не генерируются из JSON.

## Идеи улучшения

1. Таймер всех проливов подряд: «Пролив 3 из 7, +5 с» с вибрацией/звуком в конце.
2. Выбор объёма посуды (гайвань 100 мл / чайник 200 мл / кружка 300 мл) с пересчётом граммов и «западного» способа заварки.
3. Экспорт шпаргалки картинкой (Canvas → PNG) для сторис и печать на стикер.
4. Сохранение выбора в localStorage, чтобы при повторном визите гид открывался с «вашим» чаем.
5. Звуковой слой: тихое бульканье пузырей, звон таймера (по кнопке, выключено по умолчанию).
6. Больше сортов внутри семейств (Те Гуань Инь, Да Хун Пао, шэн/шу пуэр) с отдельными параметрами.
7. Перетаскивание щепоток мышью/пальцем на весы (Draggable) вместо кнопок.
8. Анимация пара и воды на Canvas для ещё более живой сцены на мощных устройствах.
9. Английская версия и переключатель языка.
10. Минификация CSS/JS простым скриптом — для хостингов без сжатия.
