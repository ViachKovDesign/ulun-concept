# Решения (DECISIONS)

Каждое решение — одна строка.

- Палитра: глубокий зелёный чайного листа `#1E4230` + бледно-рисовый `#F2EDDC` (контраст 9.55:1), оттенки — только прозрачность этих двух цветов; вторичный текст не ниже 80 % непрозрачности (5.57:1, AA).
- Шрифты из Google Fonts, размещены локально в /fonts (woff2, кириллица + латиница, лицензия OFL): дисплейный Unbounded (400–800), текстовый Nunito (400–800).
- GSAP 3.15.1 и ScrollTrigger 3.15.1 (npm `gsap`), Lenis 1.3.27 (npm `lenis`) — минифицированные файлы скопированы в /vendor, без CDN.
- Морфинг листа — свой: две формы листа с одинаковой структурой кубических кривых, числа интерполируются по прогрессу GSAP-твина; flubber и MorphSVGPlugin не подключаю (меньше веса, полный контроль).
- Подход к заварке — «гунфу»: гайвань ~100 мл, граммы считаются «на 100 мл».
- Шаг весов — щепотка 1 г, диапазон 0–12 г; шаг термометра 1 °C, диапазон 60–100 °C.
- Ползунки — нативные input range с <label> и <output>; весы управляются и ползунком, и кнопками «+/− щепотка» (44px).
- Pin-секции (ScrollTrigger) только на ширине ≥ 1024px и без reduced-motion; на телефоне главы идут потоком с мягким появлением — надёжнее для тача.
- Lenis включается только без reduced-motion; на тач-устройствах остаётся нативный скролл (по умолчанию в Lenis).
- Курсор-листик — спутник системного курсора (системный не скрываю ради доступности), только (hover:hover) и (pointer:fine), без reduced-motion.
- Без JS: интерактивные элементы скрыты классом .js-only, все главы — обычная статья + таблица параметров всех чаёв.
- Данные чаёв — /data/teas.json + инлайн-копия в <script type="application/json"> для открытия через file:// (fetch там не работает).
- Время таймера можно ускорить для тестов: параметр URL `?speed=20` или `window.ULUN.setSpeed(n)`.
- Шпаргалка показывает выбранные пользователем значения и, если они не попадают в рекомендацию, — пометку с рекомендацией.
- Форма записи демо: ничего не отправляет, проверка полей в браузере + своя проверка телефона, сообщение «Запись принята (демо)».
- Адрес чайной — вымышленный и обобщённый («Москва, у Чистых прудов»), без реальных телефонов и почты.
