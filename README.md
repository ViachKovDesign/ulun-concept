# УЛУН — интерактивный гид «Как заварить чай правильно»

Концепт-сайт вымышленной московской чайной «УЛУН». Шесть интерактивных глав: выбираете чай, ставите температуру воды, кладёте лист на весы, заливаете — лист разворачивается, идёт таймер — и в конце забираете шпаргалку.

> Концепт-проект. Бренд вымышленный. Дизайн и разработка — [ViachKovDesign](https://viachkovdesign.github.io).

![Обложка](img/og.png)

## Как открыть на своём компьютере

Самый простой способ — дважды щёлкнуть по файлу `index.html`. Всё заработает: данные о чае на этот случай встроены прямо в страницу.

Чуть правильнее — через маленький локальный сервер (так работает и загрузка `data/teas.json`):

1. Откройте терминал в папке проекта.
2. Запустите одну из команд (что установлено — то и подойдёт):

```bash
python3 -m http.server 8000
```

```bash
npx serve .
```

3. Откройте в браузере `http://localhost:8000` (или адрес, который покажет `serve`).

Сборщик не нужен: это обычные HTML, CSS и JavaScript.

## Как опубликовать на GitHub Pages (бесплатно)

1. Залейте проект в репозиторий на GitHub (файл `index.html` должен лежать в корне).
2. Откройте репозиторий → **Settings** → слева **Pages**.
3. В блоке **Build and deployment** выберите **Source: Deploy from a branch**.
4. Выберите ветку (например, `main`) и папку **/ (root)** → **Save**.
5. Через 1–2 минуты сайт появится по адресу `https://<ваш-логин>.github.io/<имя-репозитория>/` — ссылка будет показана там же, на странице Pages.

После публикации поправьте в `index.html` адреса в `<link rel="canonical">`, `og:url` и `og:image`, если имя репозитория или логин другие (сейчас стоит `https://viachkovdesign.github.io/-/`). Ссылки для соцсетей должны быть полными, с `https://`.

## Структура

```
index.html          — вся страница: разметка, SVG-иллюстрации, встроенная копия данных
css/style.css       — стили (два цвета, адаптив, reduced-motion)
js/main.js          — логика глав, морфинг листа, таймер, шпаргалка, форма, анимации
data/teas.json      — параметры пяти чаёв (источник правды)
vendor/             — GSAP 3.15.1, ScrollTrigger 3.15.1, Lenis 1.3.27 (локально, без CDN)
fonts/              — Unbounded и Nunito из Google Fonts (woff2, лицензия OFL)
img/                — favicon (SVG + PNG), обложка Open Graph 1200×630
screenshots/        — скриншоты всех ширин и состояний
tests/              — автотесты и съёмка скриншотов на Playwright
tools/              — служебные скрипты (встроить данные, отрисовать OG и иконки)
DECISIONS.md        — принятые решения, по одной строке
REPORT.md           — отчёт о проделанной работе
```

## Если меняете данные о чае

1. Отредактируйте `data/teas.json`.
2. Обновите встроенную копию в `index.html` (нужна для открытия двойным щелчком):

```bash
python3 tools/inline-data.py
```

3. Таблицу «Все пять чаёв коротко» и подписи на карточках в `index.html` поправьте вручную — они нужны для версии без JavaScript.

## Проверки

Нужен Node.js и Playwright (`npm i -D playwright`, затем `npx playwright install chromium`). Сначала запустите локальный сервер на порту 8765:

```bash
python3 -m http.server 8765
```

Затем в другом окне терминала:

```bash
node tests/e2e.cjs
```

```bash
node tests/screens.cjs
```

```bash
node tests/states.cjs
```

- `e2e.cjs` — сценарий «улун → 90 °C → 7 г → залить → таймер → шпаргалка», копирование и демо-форма; время ускорено параметром `?speed=20`.
- `screens.cjs` — полностраничные скриншоты 375/768/1280/1920, проверка консоли и горизонтального скролла.
- `states.cjs` — скриншоты глав и состояний, reduced-motion и версия без JS.

Подсказка: таймер можно ускорить и вручную — откройте страницу с `?speed=10` в адресе.
